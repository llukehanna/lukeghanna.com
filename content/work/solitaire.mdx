Klondike solitaire with nothing in the way: no ads, no accounts, no server. It is a static page that installs as an app and plays offline. The part that matters is one TypeScript solver, which runs at build time to pick the deals and in a Web Worker at runtime to answer the question every solitaire player eventually asks: can I still win this?

## Every deal is proven winnable

Random Klondike deals are sometimes impossible, and a player cannot tell a lost deal from a lost game. So there are no random deals. A 32-bit seed drives a mulberry32 generator and a Fisher–Yates shuffle, so a seed fully determines a deal, and a build script solves seeds across every CPU core until it has 2,000 winnable ones for each draw mode. The banked solutions run 118 to 261 moves in draw one and 101 to 189 in draw three.

A new game picks a random banked seed and skips the last 200 the player has seen. Solutions are not stored: the solver is deterministic, so the tests re-solve banked seeds with the bank's own node budget and replay each solution through the engine to a win, a sample on every run and all 4,000 on demand.

The guarantee has one stated limit. The solver assumes unlimited passes through the stock, and Vegas scoring allows one pass in draw one and three in draw three, so the settings say plainly that a Vegas deal may not be winnable.

## One solver, three jobs

The search is a depth-first search with a transposition table. Its state key sorts the tableau columns, so positions that differ only in which column holds which pile collapse into one, and it encodes the stock as a position in its draw cycle rather than as two piles. Safe foundation moves are applied without branching, and stock play is folded into compound moves (draw until a given card is on top, then play it), which removes most of the branching a Klondike search wastes on the stock.

It runs in two passes. A pruned pass that only considers useful tableau moves finds most wins quickly. If it runs out of moves, a complete pass searches everything, and only a complete pass that runs out can answer "unwinnable". Running out of budget or time always answers "couldn't tell", never "lost".

The hint is the first move of an actual winning line, not the first legal move. The Winnable? button runs the same search and reports the verdict, and the check also runs by itself when the player has no productive moves left. When the answer is no, rewind walks back through the game's history: it tests the newest position first, then binary-searches the rest, since the opening deal is known to be winnable, and undoes to the most recent position the solver can prove.

## Nothing moves unless you move it

Many solitaire apps play safe cards to the foundations for you, and this one used to by default. Cards moving that the player never touched made the game harder to read, so auto-move is now opt-in and off for everyone, including players who had it on. With it on, a card the player pulls down from a foundation stays down: the cards held back are derived from the turn history rather than stored, so undo, redo and a reload need no extra state.

The one thing that always moves by itself is the finish. Once every tableau card is face up, the game is usually decided, but not always: draw three can bury a card in the stock, and Vegas can run out of passes. Auto-finish tries a greedy pass first (play the lowest card that fits a foundation, otherwise draw) and falls back to a short solver run that respects the pass limit. If neither finds a finish, play just continues, and it checks again after the next move. When it does fire, input locks and the cards leave one every 110 ms, each on the normal move transition, so the finish reads as a stream you can watch. The win waits until the last card lands, then the classic bouncing-card cascade plays on a canvas that is never cleared. Reduced motion quickens the finish rather than skipping it and leaves out the cascade; only the Animation: Off setting makes the finish instant.

## The table

There are three tables, switched from the toolbar: Studio, a warm charcoal with a leather grain and a stitched rail; Felt, green with a choice of five cloths; and Paper, a light linen. Every texture is CSS gradients and inline SVG noise, so the table ships no image files. The cards are drawn in HTML: one large rank-and-suit index in the top-left corner, where it stays readable in a fanned column, and one big pip, with no court art. The four-colour deck and five card backs, Deco by default, work on every table. Type is Geist, bundled so it works offline.

All 52 cards are absolutely positioned elements keyed by card id, and each card's position is a pure function of the game state and the layout, so every state change animates through CSS transforms with no animation code per move. A card turning face up does a real 3D flip. A card that can be picked up lifts slightly under the pointer, and tapping a card with nowhere to go shakes it and every card above it, and moves nothing. Tap sends a card to its best destination, double-tap sends it to a foundation, drag works with a five-pixel threshold, Space draws, and Enter picks up and drops, so the whole game plays from the keyboard, with every move announced to screen readers.

The game is saved after every move as the seed plus the list of turns, and replayed on load, so undo, redo, the timer and the score survive a reload. Every read from storage is validated, settings from older versions migrate once on load, and the app still works when storage is unavailable. The sounds are synthesized with Web Audio, so there are no audio files.

## Status

Live at solitaire.lukeghanna.com as static files on Vercel, installable as an app, and fully playable offline once loaded; a new deploy takes over open tabs as soon as it installs. On an iPhone home screen it runs full-bleed under a translucent status bar, with the page behind the safe areas matching the table, and a gold-spade icon on leather. Draw one and draw three, standard, Vegas or no scoring, and stats per draw mode, with a one-time import from solitaired.com. Klondike only for now; the engine is structured for FreeCell and Spider next. 183 unit tests across 25 files and 34 Playwright tests, run on desktop and a Pixel 7 profile, including one that plays a banked deal to a win, one that moves cards with the keyboard alone, and one that checks a tap with no move shakes and moves nothing.
